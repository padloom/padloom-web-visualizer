# Padloom Web Visualizer 🎨

![Padloom Logo](https://padloom.com/cdn/shop/files/padloom-black-logo-1.svg)

**Padloom Web Visualizer** is a Chrome extension designed to help gamers and setup enthusiasts preview custom mouse pads in real-time.

## 🚀 About the Project
This open-source tool allows users to verify print quality and dimensions before purchasing custom desk mats. It is part of the ecosystem built for [Padloom.com](https://padloom.com).

## ✨ Features
* **Real-time Preview:** See how your image looks on a mouse pad.
* **Size Calibration:** Automatically adjusts for XXL and Extended sizes.
* **High-Quality Render:** Ensures your setup looks perfect.

## 🛠 Installation (For Developers)
1.  Clone this repository.
2.  Open Chrome and go to `chrome://extensions/`.
3.  Enable "Developer mode".
4.  Click "Load unpacked" and select the folder.
